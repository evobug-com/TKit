# TKit has moved

**TKit now lives at [git.evobug.com/Evobug/TKit](https://git.evobug.com/Evobug/TKit).**

</div>

---

TKit 1.0 is a complete rewrite in Rust: faster, lighter, installed just for
your account (no administrator rights), with Kick support next to Twitch.
New releases, issues and development are on Forgejo:

- **Download:** [git.evobug.com/Evobug/TKit/releases](https://git.evobug.com/Evobug/TKit/releases)
- **Source code and issues:** [git.evobug.com/Evobug/TKit](https://git.evobug.com/Evobug/TKit)

## Already using an older TKit (0.0.1-dev.x)?

Just let it update. The [v1.0.0 release](https://github.com/evobug-com/TKit/releases/tag/v1.0.0)
here moves an old installation to TKit 1.0: it removes the old version from
Program Files (Windows asks for permission once) and installs the new one.
Your settings and mappings are kept; you only need to connect Twitch again.
From then on TKit updates itself from git.evobug.com.

This repository is kept read-only so that older installations can still find
that update. The code of the old Flutter app stays here for reference.
